1. Structure d'un document HTML

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Mon titre</title>
</head>
<body>
  ... tout le contenu visible ici ...
</body>
</html>
  • <!DOCTYPE html> = déclaration (pas une balise) → HTML5.
  • <head> = infos invisibles (titre, encodage).
  • <body> = contenu visible.

4. Les formulaires ⭐ (le gros morceau)

<form action="#" method="get">
  <label for="nom">Nom</label>
  <input type="text" id="nom" name="nom" required>
  <input type="submit" value="Envoyer">
</form>

Attributs du <form>

  • action="#" = où envoyer (# = nulle part).
  • method="get" → données visibles dans l'URL.
  • method="post" → données invisibles (sécurisé).

Types d'<input> (⚠️ auto-fermante)

TypeRôle
texttexte simple
passwordtexte masqué
emailvérifie le @

radioun seul choix par groupe
checkboxplusieurs choix possibles
submitbouton d'envoi (texte via value)

⚠️ Checkbox vs Radio (piège classique)

CheckboxRadio
Choixplusieursun seul
nameidentiqueidentique
valuedifférentdifférent
C'est le type + le name identique qui fait la différence, PAS la value.

Autres éléments

  • <select> + <option> = liste déroulante.
  • <textarea rows="5" cols="20"> = zone multi-lignes.
  • <label for="id"> = étiquette liée (doit correspondre à l'id).

Attributs utiles

  • name → obligatoire pour que la valeur soit envoyée.
  • value → valeur envoyée / texte du bouton.
  • required → champ obligatoire.
  • placeholder → texte d'exemple grisé.

5. HTML sémantique (HTML5)

Des balises qui décrivent leur contenu (au lieu de <div> partout). Aucun effet visuel, mais SEO + accessibilité.

BaliseRôle
<header>en-tête
<nav>menu de navigation
<section>section
<article>contenu indépendant
<aside>contenu à côté (barre latérale)
<footer>pied de page

Non-sémantique : <div> (bloc) et <span> (inline).

8. Les 7 points pièges à retenir

  1. <input>, <img>, <br> sont auto-fermantes → pas de </input>.
  2. Radio = un seul choix ; checkbox = plusieurs. Même name, value différente.
  3. get = URL visible ; post = caché/sécurisé.
  4. Un tableau se construit ligne par ligne (<tr>).
  5. <label for="x"> doit pointer vers un id="x" identique.
  6. La sémantique n'a aucun effet visuel — c'est du sens.
  7. &copy; s'écrit en entité HTML, pas en caractère collé.
